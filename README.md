# Геометрическая библиотека

Учебный проект для лабораторной работы №2 **«Документирование»** по ИСРПО.
Модули рассчитывают площади и периметры четырёх фигур. Интерфейс аналогичен
файлам первой лабораторной; основная работа здесь - документация проекта.

## Требования

- Python 3.
- Только стандартная библиотека: устанавливать пакеты не требуется.
- Все размеры положительные, в одинаковых единицах.
- Для периметра треугольника передаются стороны существующего треугольника.

## Быстрый запуск

Откройте терминал в каталоге проекта и запустите интерактивный Python:

```console
python
```

```pycon
>>> import rectangle
>>> rectangle.area(3, 4)
12
>>> rectangle.perimeter(3, 4)
14
```

**Важно:** проверки аргументов нет; вызывающий код соблюдает предусловия.

В корне проекта:

```console

```

Восемь примеров должны завершиться без ошибок.
Дополнительные примеры из Markdown можно выполнить в интерпретаторе Python.
