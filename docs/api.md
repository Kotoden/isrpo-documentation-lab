# Справочник функций

Примеры выполняются из корня репозитория.

> Положительные размеры и существование треугольника - предусловия.
> Функции вычисляют формулы и не выполняют проверку аргументов.

## Модуль `circle`

### `circle.area(r)`

Площадь круга по радиусу r: pi * r ** 2.

r - положительное число; результат - float, квадратные единицы.

```pycon
>>> import circle
>>> round(circle.area(2), 5)
12.56637
```

### `circle.perimeter(r)`

Длина окружности по радиусу r: 2 * pi * r.

r - положительное число; результат - float, единицы длины.

```pycon
>>> import circle
>>> round(circle.perimeter(2), 5)
12.56637
```

## Модуль `square`

### `square.area(a)`

Площадь квадрата со стороной a: a ** 2.

a - положительное число; результат - число, квадратные единицы.

```pycon
>>> import square
>>> square.area(3)
9
```

### `square.perimeter(a)`

Периметр квадрата со стороной a: 4 * a.

a - положительное число; результат - число, единицы длины.

```pycon
>>> import square
>>> square.perimeter(3)
12
```

## Модуль `rectangle`

### `rectangle.area(a, b)`

Площадь прямоугольника со сторонами a и b: a * b.

a, b - положительные числа; результат - число, квадратные единицы.

```pycon
>>> import rectangle
>>> rectangle.area(3, 4)
12
```

### `rectangle.perimeter(a, b)`

Периметр прямоугольника со сторонами a и b: 2 * (a + b).

a, b - положительные числа; результат - число, единицы длины.

```pycon
>>> import rectangle
>>> rectangle.perimeter(3, 4)
14
```

## Модуль `triangle`

### `triangle.area(a, h)`

Площадь треугольника по основанию a и высоте h к нему: a * h / 2.

a, h - положительные числа; результат - float, квадратные единицы.

```pycon
>>> import triangle
>>> triangle.area(4, 3)
6.0
```

### `triangle.perimeter(a, b, c)`

Периметр треугольника: a + b + c.

a, b, c - положительные стороны существующего треугольника.

```pycon
>>> import triangle
>>> triangle.perimeter(3, 4, 5)
12
```
