# Описание решения

**Геометрическая библиотека** предоставляет восемь функций: площадь и периметр
круга, квадрата, прямоугольника и треугольника. Функции размещены в отдельных
модулях Python; программа не требует сторонних библиотек.

## Структура

| Файл | Назначение |
| --- | --- |
| `circle.py` | Площадь круга и длина окружности |
| `square.py` | Площадь и периметр квадрата |
| `rectangle.py` | Площадь и периметр прямоугольника |
| `triangle.py` | Площадь по основанию и высоте; периметр по трём сторонам |
| [api.md](api.md) | Аргументы, формулы, примеры всех функций |
| [CHANGELOG.md](CHANGELOG.md) | История проекта с хешами коммитов |

## Использование

1. Откройте терминал в корне проекта.
2. Выполните пример из [корневого README](../README.md).
3. Для остальных функций используйте [справочник API](api.md).

> Все размеры задаются в одинаковых единицах и должны быть положительными.
> Для треугольника стороны должны удовлетворять неравенству треугольника.
> Проверка этих условий остаётся на вызывающем коде. Библиотека их не проверяет.

Площадь измеряется в *квадратных единицах*, периметр - в единицах длины.
Результат зависит от типов аргументов; деление в `triangle.area` и использование
`math.pi` в `circle` дают `float`.

## Проверка примеров

```console
python -m doctest -v circle.py square.py rectangle.py triangle.py
```

`doctest` сравнивает фактические результаты с примерами в docstring.
Для окружности применяется округление до пяти знаков.
